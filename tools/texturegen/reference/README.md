# Vanilla rock substrates

`assets/minecraft/textures/block/stone.png` and `deepslate.png` are the original
Minecraft Java 1.21.1 textures, extracted from the local client JAR. These source
assets belong to Mojang/Microsoft; they are not original artwork of this mod.

The texture generator preserves them exactly outside the mineral inclusion masks.
Uranium uses deepslate, matching its configured world generation target. Borax
uses stone. The existing thorium texture also uses stone (no new block is added).
